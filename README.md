# Portfolio Website

Personal portfolio website built with **HTML** and **CSS**, published using **GitHub Pages**.  
The website presents my skills, certificates, and contact information in a clean and modern layout.

## 🌍 Live Demo

🔗 **GitHub Pages:**  
https://sebusiektech.github.io/portfolio-website/ (no active!)

## 📌 About the Project

This project is my personal portfolio website created to:
- Present my technical skills
- Showcase certificates
- Introduce myself as a future programmer
- Provide easy contact access

The site is fully static, fast, and easy to deploy with GitHub Pages.

## 🛠️ Technologies Used

- **HTML5** – semantic website structure  
- **CSS3** – styling, layout, hover effects, responsiveness  
- **Font Awesome** – icons  

## 📄 Website Sections

- **About** – short introduction and profile photo  
- **Skills** – overview of my technical knowledge  
- **Certificates** – completed courses and certifications  
- **Contact** – email address
